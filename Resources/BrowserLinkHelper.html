怎样拿到其他 Mac 上使用？

把这个 HTML 文件通过隔空投送、U 盘或文件传输发到另一台 Mac。保存到本机后，在访达中右键文件 →“打开方式”→“Safari 浏览器”。粘贴那台 Mac 上需要处理的链接，按上面的三步操作即可。无需安装软件，也不依赖原电脑的文件路径。

每台 Mac 都要分别操作；传送页面不会传送本机的系统偏好。平时使用的默认浏览器可在“系统设置 → 桌面与程序坞 → 默认网页浏览器”中确认。

小红书短链和长链接要分别处理吗？

可能需要。www.xiaohongshu.com、xhslink.com 等域名可能有各自的关联。请使用实际遇到问题的完整链接；如果短链最终跳转到其他域名，后者也可能需要单独操作。本页会列出每条链接的域名，便于检查。

没有“打开链接”，或操作后仍然跳 App？

先确认当前用的是 macOS 上的 Safari，并且右键的是生成后的绿色链接。若菜单没有对应选项，或操作后仍跳 App，可以临时把完整链接复制到默认浏览器的地址栏打开。

这是操作辅助页，页面本身不会直接修改系统设置。选择能否被记住取决于 macOS 版本和应用。此前已在一台 macOS 26.6.2 的小红书长链接上验证 Safari 菜单方法；其他 Mac、重启后的状态和其他域名尚未实测。
