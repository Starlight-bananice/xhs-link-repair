## Windows 使用教程

### 1. 准备 MuMu 和小红书

1. 安装并启动 MuMu 模拟器，在模拟器中安装安卓版小红书。
2. 打开小红书，手动完成登录及可能出现的验证，确认能浏览笔记。
3. 确认 MuMu 能将安卓剪贴板同步到 Windows：在小红书笔记中点“分享 → 复制链接”，再到 Windows 文本框粘贴，应出现分享文案或链接。若没有，请检查 MuMu 的剪贴板同步设置。

此前安装的 Electron 网页封装版小红书不能代替这里的安卓版客户端。

### 2. 启动 Windows 程序

1. 下载上方 Windows ZIP，解压到可写文件夹。
2. 双击 `小红书链接修复.exe`，无需另装 Python 或 Microsoft Excel。
3. 程序会查找运行中的 MuMu 及已安装小红书的在线设备。若未找到 ADB，点击“选择 adb.exe…”，选择 MuMu 安装目录中的 `nx_main\adb.exe`，再点“检测模拟器”。例如安装到 `E:\MuMuPlayer` 时选择 `E:\MuMuPlayer\nx_main\adb.exe`。
4. 只有一个设备时自动选中；多个设备时请手动选择目标设备。MuMu 同一实例的两种 ADB 连接名称会按管理器提供的地址过滤，避免重复显示。

### 3. 批量修复

1. 在输入框粘贴笔记长链接、官方分享短链、分享文案或 24 位笔记 ID；支持混合粘贴多条，也可点击“导入 TXT…”。主页链接不作为笔记处理。
2. 点击“开始修复”。程序打开安卓客户端中的目标笔记，识别分享控件并点击“复制链接”，然后展开新短链，检查笔记 ID 和 `xsec_token`。
3. 同一笔记在一批中只处理一次；输入已有分享参数时也会重新分享，不把旧参数直接作为修复结果。
4. 运行期间不要操作模拟器中的小红书，也不要在 Windows 或模拟器中复制其他内容，以免干扰剪贴板同步。程序不依赖固定屏幕坐标。
5. 需要中止时点“停止”。程序取消后续操作并保存已完成结果，未处理项也会留在 Excel 中。

### 4. 查看与导出

每处理一条都会自动保存 Excel，默认位置为 **文档\小红书链接修复结果**。结果包含序号、原始链接、笔记 ID、状态、新链接、说明和处理时间。

- “打开结果文件夹”：查看自动保存的 `.xlsx` 文件。
- “导出 Excel…”：将当前批次另存到选定位置。
- “复制选中结果”：复制结果表中选中行的新链接。
- 需要重试时，将相应行的原始链接重新粘贴并开始；当前 Windows 版不自动恢复上次输入或批次。

| 状态 | 含义与处理 |
| --- | --- |
| 成功 | 客户端已重新分享，笔记 ID 匹配且包含 `xsec_token`；不等于已验证浏览器展示 |
| 待核验 | 已取得分享链接，但展开或参数核验尚未完成；保留短链，可稍后重试 |
| 需处理 | 登录/验证提示、剪贴板未同步或 ID 不符；停止批次，先在 MuMu 中处理提示 |
| 失败 | 输入短链展开、打开笔记或控件识别失败；查看说明列，不据此认定笔记已删除 |
| 重复 / 未处理 / 已停止 | 分别表示批次中同一笔记、尚未执行或已取消的项目 |

### Windows 常见问题

- **找不到设备**：确认 MuMu 安卓系统已启动、小红书已安装，选择正确的 `adb.exe` 后重新检测。
- **未收到新复制的分享链接**：先手动验证 MuMu 剪贴板同步；转换期间不要复制其他内容。
- **找不到分享或复制按钮**：确认已经登录、目标笔记可访问且没有弹窗遮挡；客户端改版后可能需要适配。
- **提示 ID 不符**：程序会丢弃错误链接并停止。检查是否同时操作了客户端，再重试原始链接。
- **Excel 保存失败**：关闭正在占用结果文件的 Excel/WPS，再用“导出 Excel…”另存；不要直接关闭程序丢失尚未保存的结果。
- **如何更新**：从本发布页下载新的 Windows 包，退出旧程序后替换。Windows 当前不支持应用内自动更新、历史恢复或 Excel 输入导入；这些功能不要与下方 macOS 说明混淆。

### Windows 构建和验证范围

在仓库目录用 Windows PowerShell 执行 `./Windows/build.ps1`，生成 `dist/XHSLinkRepair-Windows/小红书链接修复.exe` 和 `dist/XHSLinkRepair-0.5.13-windows-x64.zip`；脚本同时执行输入解析、参数保留、安卓控件定位和 Excel 导出自检。

2026-10-02 已在本机 MuMu + 安卓小红书 9.31.2 上用打包程序完成两条真实笔记的自动重新分享，两条结果均通过 ID 和 token 核验并导出 Excel。未验证浏览器最终展示、其他模拟器或所有客户端版本。真实测试链接和结果不提交仓库。

程序不读取账号密码或浏览器 Cookie，不伪造分享参数；笔记访问权限仍由小红书决定。输入和结果保存在本机，网络请求用于官方短链展开。

## macOS 使用条件

- Apple Silicon Mac（M 系列芯片），macOS 13 或更新版本。
- 已安装并登录 iPad 版小红书，且能在客户端中正常打开目标笔记。
- 为本工具开启 macOS 辅助功能权限。
- 当前提供 macOS arm64 安装包，不提供 Intel Mac 版本；Windows 用户请使用上方的 Windows 下载包。

本工具依赖小红书客户端的窗口操作。运行期间请让小红书保持前台，不要切换应用、移动窗口、操作鼠标或复制其他内容。它不是完全后台运行的爬虫，也不能绕过笔记访问权限。

## 恢复链接通过默认浏览器打开

如果在备忘录、文档或聊天中点击小红书链接总被小红书 App 接管，点击软件结果区上方的 **恢复浏览器打开…**。程序会用 Safari 打开内置的离线助手，无需另外下载 HTML 文件。

1. 在助手页面粘贴遇到问题的完整链接或分享文案，点击 **生成操作链接**。
2. 在生成的链接上右键，选择 Safari 原生菜单最上方的 **打开链接**。
3. 回到原来的备忘录、文档或聊天，普通点击同一链接，确认是否进入你设置的默认浏览器。

这是之前验证过的 Safari 菜单操作流程，仍需要手动执行右键步骤。助手页面本身不会直接修改系统偏好；能否记住选择取决于 macOS 和链接域名。此前仅在本机 macOS 26.6.2 的 `www.xiaohongshu.com` 链接上验证，重启后状态、其他 Mac 和短链域名尚未全面验证。若仍打开 App，可将完整链接粘贴到默认浏览器地址栏作为临时方式。

助手不上传或持久保存输入，保留链接查询参数。请在转换或更新结束后使用该入口，避免操作 Safari 打断客户端转换。

## 应用内更新

窗口右下角显示当前版本和更新按钮。启动后会检查 GitHub 最新正式版，检查本身不会下载或安装。

- 有新版时按钮显示 **更新**；点击后下载、校验安装包，并在安装完成后重新打开软件。
- 没有更高版本时显示 **已是最新版**；网络或服务错误时显示 **重试检查**，不会把检查失败当作已是最新版。
- 转换进行中不能安装更新。更新会保留输入、当前结果、Excel 保存位置和历史报告。
- 安装位置需要可写；自动安装失败时会尝试恢复原版。也可以从错误提示中的“打开发布页”手动下载。

0.5.8 及更早版本没有应用内更新，需要先手动安装带更新入口的版本。发布新版本时使用 `v主版本.次版本.修订号` 标签，上传 `XHSLinkRepair-0.5.13-macOS-arm64.zip` 并设为最新正式版；更新器核验 GitHub 提供的安装包 SHA-256、应用身份和版本，不安装草稿或预发布版本。

## 下载与安装

1. 打开 [Releases 下载页](https://github.com/Starlight-bananice/xhs-link-repair/releases/latest)，下载 `XHSLinkRepair-版本号-macOS-arm64.zip`，不要选择源码压缩包。
2. 解压，将 `小红书链接修复.app` 拖入“应用程序”文件夹。
3. 先打开 iPad 版小红书并登录，确认客户端窗口可见。
4. 打开 `小红书链接修复.app`。应用使用本地临时签名，未经过 Apple 公证；如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中对该应用选择“仍要打开”。
5. 在“系统设置 → 隐私与安全性 → 辅助功能”中允许 **小红书链接修复** 控制电脑。如果列表中没有它，点击“＋”选择刚安装的 App。
6. 返回工具，开始转换。出现权限提示后，需要授权完成再重新点击开始。

更新时先退出旧版，再用新版替换原来的 App；尽量固定安装位置。若更新后开关已开启但仍提示无权限，移除辅助功能列表中的旧条目，再添加新版 App。

## 批量转换步骤

1. 把链接或笔记 ID 粘贴到上方输入框。建议每行一条，也支持从 Excel 复制整列或表格内容。
2. 按需点击 **选择保存位置…** 指定 Excel 文件夹。工具会记住选择；默认是桌面的 **小红书链接转换结果** 文件夹。
3. 保留默认勾选的“控件识别失败时按窗口位置点击”。工具先查找笔记页右上角的实际分享按钮；无法识别时，分享按钮的坐标回退按窗口右上角的固定边距点击，不会因窗口高度或显示器位置改变而偏移。若新版客户端布局改变，可取消勾选，仅使用控件识别。
4. 点击 **开始批量转换**。工具按输入顺序处理；遇到官方短链会先联网展开、提取笔记 ID，再打开客户端重新分享。短链、长链接和裸 ID 指向同一笔记时只处理一次，保留首次输入作为原始链接。
5. 等待进度完成。复制后会立即开始返回首页，同时展开短链；正常条目从复制完成时起至少间隔 2 秒再继续，已经经过的恢复和网络时间会计入间隔，不额外叠加等待。批次结束时不再自动汇总复制成功链接。
6. 工具自动生成并打开 `.xlsx` 文件，保存到界面显示的文件夹。点击 **打开 Excel** 可再次打开本批文件；点击 **查看历史记录** 可浏览以前的报告。

### 可以输入什么

- `http://xhslink.com/o/短码`、`https://xhslink.com/a/短码` 等官方分享短链。
- `xhslink.cn`、`www.xhslink.com`、`www.xhslink.cn` 域名的完整 `http` / `https` 短链。
- `https://www.xiaohongshu.com/explore/笔记ID`
- `https://www.xiaohongshu.com/discovery/item/笔记ID`
- 含 `xsec_token` 的完整笔记链接（仍会通过客户端重新分享）。
- 单独的 24 位十六进制笔记 ID。

上面的“笔记ID”和“短码”是占位说明，使用时需要替换成真实内容。可以混合粘贴短链、长链接、笔记 ID、分享文案或 Markdown 链接，程序会保留顺序并去重。

以 `http://` 开头的官方短链会通过 HTTPS 请求展开，Excel 中仍保留输入的原始地址。

短链展开仅用于定位笔记；程序随后通过已登录的客户端重新获取分享链接，不直接将原短链的旧签名作为修复结果。展开超时或没有指向笔记的短链会显示“失败”，并在 Excel 保留原短链和原因，随后继续其他条目；不会据此判定“已删除”。

### 保存位置和历史记录

- **选择保存位置…**：选择一个文件夹，后续转换结果自动保存到那里；退出并重新打开软件后仍保留此设置。转换期间不能修改保存位置。
- **查看历史记录**：按文件修改时间倒序显示默认目录和历次选择目录中的报告，显示文件名及保存位置。双击一条记录或点击“打开 Excel”即可查看，也可点击“在访达中显示”定位文件。
- 旧版保存在桌面默认目录中的报告会自动出现在历史记录中；切换保存位置不会移动或删除原报告。
- 历史记录根据仍存在的导出 Excel 生成，只列出本工具命名格式的报告。如果手动删除、改名或移到未选择过的目录，该文件将不再出现在列表中；点击“刷新”可更新列表。
- 同一秒内多次导出时会添加序号，避免覆盖先前的报告。

### 停止与重试

点击 **停止** 后，工具会在当前链接处理结束后停止，并导出已处理结果，不是立即中断正在进行的点击或请求。在输入短链展开期间停止，会等待本次网络请求结束后退出，不再打开客户端；没有已处理结果时不生成空报告。

对加载、分享和复制等暂时性故障，页面恢复成功后最多自动重试一次。需要手动重试时，将失败项的原链接或 ID 再粘贴到输入框，点击开始即可。权限不足、窗口离开前台或无法安全恢复首页时会停止批次。

## 如何看结果

结果区每行对应一条去重后的输入；Excel 包含序号、原始链接、笔记 ID、状态、新链接、说明和处理时间。

| 状态 | 含义 |
| --- | --- |
| 成功 | 已取得带 `xsec_token` 且笔记 ID 与本条一致的链接 |
| 待核验 | 已取得官方分享短链，但未能展开并核验目标笔记；短链保留在结果区和 Excel 中 |
| 已删除 | 客户端显示“当前内容无法展示”等无法查看提示时的统一结果标签，具体提示保留在 Excel 说明中 |
| 失败 | 输入短链展开、加载、分享、复制、窗口状态或链接归属校验等环节失败；查看说明列定位原因 |

成功链接统一整理为：

```text
https://www.xiaohongshu.com/explore/笔记ID?xsec_token=客户端返回的凭证&xsec_source=app_share
```

“成功”表示已取得并核对分享链接，不代表已经逐一在浏览器中打开验证。删除、私密、仅粉丝可见等情况仍受平台权限限制。

## 常见问题

**提示输入小红书短链、笔记链接或 24 位笔记 ID**

确认短链包含 `http://` 或 `https://` 和完整短码，或者输入笔记详情链接、24 位 ID。作者主页、搜索页不作为笔记输入。

**短链显示“未能展开”**

检查网络，或从小红书重新复制完整分享链接再试。展开失败表示尚未取得目标笔记 ID，不表示笔记已删除；失败原短链会保存在报告中。

**提示需要辅助功能权限**

按上方授权步骤操作，注意选择当前使用的 App。移动安装位置或更换版本后，可能需要移除旧条目再重新添加。

**提示小红书窗口不在前台**

工具已停止点击。切回小红书，确认没有其他窗口遮挡，再在工具中重试未完成的链接。处理期间不要切换到其他应用。

**找不到分享按钮、复制链接，或剪贴板没有变化**

确认客户端已登录、页面已加载、窗口可见。工具会随窗口位置重新定位分享按钮；若客户端改版后按钮位置改变，可尝试关闭坐标回退，仅使用控件识别。自动恢复后仍失败的条目会保留原因。

**某条显示“已删除”后还会继续吗？**

会先退出页面，并等待客户端延迟跳转结束，确认首页稳定后再继续。这段保护等待用于防止失效链接影响后续条目。

**为什么回到首页后有时还要等？**

短链网络请求尚未完成时仍需等待核验；正常情况下，返回首页、短链展开与最小间隔会重叠，不再重复确认已经稳定的首页。失效恢复和单次故障重试仍保留必要等待。

**可以隐藏小红书或同时操作其他应用吗？**

不建议。工具使用客户端窗口、鼠标和系统剪贴板；窗口离开前台时会停止点击。

**Excel 没有自动打开怎么办？**

点击“查看历史记录”，或到界面显示的保存文件夹查找本批文件，用 Excel、WPS 或其他支持 `.xlsx` 的软件打开。如果界面提示“Excel 保存失败”，按具体错误处理。

## 从源码构建

安装 Xcode Command Line Tools（`xcode-select --install`），在 Apple Silicon Mac 上进入仓库目录执行：

```sh
./build.command
./小红书链接修复.app/Contents/MacOS/XHSLinkRepair --self-test
```

生成的 App 位于仓库根目录。构建脚本指定 `arm64-apple-macosx13.0` 目标，并使用固定签名标识。

自检覆盖短链混合输入、去重、展开失败和非笔记目标拒绝、更新版本判断、下载与安装包校验、会话恢复及安装失败回退、保存位置持久化、跨目录历史、导出重名处理、失效页恢复、延迟跳转、分享链接归属、短链重定向、返回首页与网络展开的并行处理及剩余间隔计算。测试使用虚构 ID 和测试凭证，不请求真实笔记。
