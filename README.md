# 小红书链接修复工具 0.5.3

macOS 小红书链接批量修复工具：通过已登录的 iPad 版小红书重新分享笔记，整理浏览器链接并导出 Excel。

## 下载与安装

1. 在 [Releases](https://github.com/Starlight-bananice/xhs-link-repair/releases/latest) 下载 `XHSLinkRepair-0.5.3-macOS-arm64.zip`。
2. 解压，将 `小红书链接修复.app` 拖入“应用程序”文件夹。
3. 需要 Apple Silicon Mac（M 系列芯片）、macOS 13 或更新版本，以及已安装并登录的 iPad 版小红书。未提供 Intel 或 Windows 安装包。
4. 应用使用本地临时签名，未经过 Apple 公证。若系统阻止打开，请在“系统设置 → 隐私与安全性”中对该应用选择“仍要打开”。
5. 首次运行按提示授予辅助功能权限。批量转换会操作小红书窗口、鼠标和剪贴板，运行期间请等待处理完成。

## 本次修复

- 0.5.3：结果、复制和 Excel 中的完整链接统一为 `/explore/笔记ID?xsec_token=原凭证&xsec_source=app_share`，去除其他分享参数。

- 0.5.2：短链取得带签名的笔记地址后即结束展开，避免网页端随后跳转到 `/explore` 导致错误地提示“不是当前笔记”。

- 每条开始前返回客户端首页，清理上一条笔记或作者主页；支持正常笔记页没有文字标签的返回按钮。
- 发现失效提示后先返回，并等待超过客户端的 3 秒自动跳转窗口；若旧计时器仍跳转到作者主页，再次返回。首页持续稳定后才继续下一条。
- 加载笔记、打开分享面板、等待复制期间均检测失效提示。
- 复制失败后清理残留分享面板；无法恢复首页时停止批次，避免后续链接连续失败。
- 完整链接必须属于本条笔记，拒绝作者主页和其他笔记。短链展开失败时仍保留官方短链，Excel 明确注明“未展开核验”。


把缺少 `xsec_token` 的小红书裸链接交给 iPad 版客户端重新分享，再把浏览器可打开的新链接复制出来。

## 使用方法

1. 打开 `小红书链接修复.app`。
2. 把多条裸链接、完整链接或笔记 ID 粘贴到输入框；每行一条，也可以直接粘贴整列或表格。
3. 点击“开始批量转换”。
4. 首次使用时，在 macOS“系统设置 → 隐私与安全性 → 辅助功能”中允许本工具，然后回来再点一次。
5. 工具会自动去重并逐条处理。结束后，全部成功链接已经按行复制到剪贴板。
6. 同时自动生成并打开 `.xlsx` 文件，保存位置为桌面的 `小红书链接转换结果` 文件夹。

## 键盘快捷键

- `Command-V`：在输入框粘贴
- `Command-C` / `Command-X` / `Command-A`：复制、剪切、全选
- `Command-W`：关闭窗口
- `Command-Q`：退出应用

如果开关已经开启但工具仍提示没有权限，请先在“辅助功能”列表中用减号删除旧条目，再用加号选择本文件夹中的 `小红书链接修复.app`。应用使用固定签名标识；更新后若权限失效，按上述方法重新授权。

## 工作方式

- 从整段输入中提取全部 24 位笔记 ID，保留首次出现顺序并自动去重。
- 把裸链接转换成 `xhsdiscover://item/<note_id>`，由系统直接打开 iPad 版小红书。
- 串行处理，每条完成后间隔 2 秒再继续，降低触发平台风控的概率。
- 优先通过辅助功能控件寻找“分享”和“复制链接”。
- iPad 控件没有文字标签时，使用窗口相对位置点击；默认位置按小红书 9.45.2 适配。
- 如果客户端复制的是 `xhslink.com` 或 `xhslink.cn` 官方短链，工具会尝试展开为带 `xsec_token` 的完整网页链接；展开失败时保留可直接用浏览器打开的官方短链。
- 结果区每行对应一个输入；失败项会保留笔记 ID 和失败原因。自动复制时只复制成功链接。
- Excel 包含序号、原始链接、笔记 ID、状态、新链接、说明和处理时间。
- 客户端明确显示“当前内容无法展示”时，Excel 状态为 `已删除`；权限或自动点击故障仍标记为 `失败`。

## 注意

- 需要已安装并登录 iPad 版小红书。
- 客户端大改版后，相对点击位置可能需要重新校准。
- 删除、私密、仅粉丝可见的笔记仍受原权限限制。
- 工具不读取浏览器 Cookie，不保存账号信息，也不生成或伪造 `xsec_token`。

## 从源码构建

安装 Xcode Command Line Tools（`xcode-select --install`），在 Apple Silicon Mac 上进入项目目录执行：

```sh
./build.command
./小红书链接修复.app/Contents/MacOS/XHSLinkRepair --self-test
```

自检包含虚拟时钟回归：失效后返回、旧计时器再次跳转、已在作者主页、残留分享面板、晚出现的失效提示、无法恢复和未知窗口，以及分享链接的笔记 ID/主页校验。

自检使用虚构笔记 ID 和测试凭证，不访问真实笔记。编译和自检通过不代表已在其他 Mac 或所有小红书版本上验证。
