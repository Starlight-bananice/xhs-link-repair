# 小红书链接修复工具 0.5.7

将小红书裸链接或笔记 ID 批量交给已登录的 iPad 版小红书重新分享，生成带 `xsec_token` 的网页链接，并自动导出 Excel。适合整理缺少分享参数、无法直接在浏览器打开的笔记链接。

[下载最新版 App](https://github.com/Starlight-bananice/xhs-link-repair/releases/latest)

## 使用条件

- Apple Silicon Mac（M 系列芯片），macOS 13 或更新版本。
- 已安装并登录 iPad 版小红书，且能在客户端中正常打开目标笔记。
- 为本工具开启 macOS 辅助功能权限。
- 当前提供 macOS arm64 安装包，不提供 Intel Mac 或 Windows 版本。

本工具依赖小红书客户端的窗口操作。运行期间请让小红书保持前台，不要切换应用、移动窗口、操作鼠标或复制其他内容。它不是完全后台运行的爬虫，也不能绕过笔记访问权限。

## 下载与安装

1. 打开 [Releases 下载页](https://github.com/Starlight-bananice/xhs-link-repair/releases/latest)，下载 `XHSLinkRepair-0.5.7-macOS-arm64.zip`，不要选择源码压缩包。
2. 解压，将 `小红书链接修复.app` 拖入“应用程序”文件夹。
3. 先打开 iPad 版小红书并登录，确认客户端窗口可见。
4. 打开 `小红书链接修复.app`。应用使用本地临时签名，未经过 Apple 公证；如果 macOS 阻止打开，可在“系统设置 → 隐私与安全性”中对该应用选择“仍要打开”。
5. 在“系统设置 → 隐私与安全性 → 辅助功能”中允许 **小红书链接修复** 控制电脑。如果列表中没有它，点击“＋”选择刚安装的 App。
6. 返回工具，开始转换。出现权限提示后，需要授权完成再重新点击开始。

更新时先退出旧版，再用新版替换原来的 App；尽量固定安装位置。若更新后开关已开启但仍提示无权限，移除辅助功能列表中的旧条目，再添加新版 App。

## 批量转换步骤

1. 把链接或笔记 ID 粘贴到上方输入框。建议每行一条，也支持从 Excel 复制整列或表格内容。
2. 保留默认勾选的“控件识别失败时按窗口位置点击”。该选项用于小红书控件没有文字标签的情况，位置适配基于 iPad 版 9.45.2；若新版客户端布局改变，可取消勾选，仅使用控件识别。
3. 点击 **开始批量转换**。工具会提取笔记 ID、按首次出现顺序去重，然后逐条打开笔记、分享并复制链接。
4. 等待进度完成。复制后会立即开始返回首页，同时展开短链；正常条目从复制完成时起至少间隔 2 秒再继续，已经经过的恢复和网络时间会计入间隔，不额外叠加等待。
5. 完成后，已核验的成功链接会自动按行写入剪贴板，可以直接粘贴到文档或表格。也可点击 **复制成功链接** 再复制一次。
6. 工具自动生成并打开 `.xlsx` 文件，保存到桌面的 **小红书链接转换结果** 文件夹。点击 **打开 Excel** 可再次打开本批文件。

### 可以输入什么

- `https://www.xiaohongshu.com/explore/笔记ID`
- `https://www.xiaohongshu.com/discovery/item/笔记ID`
- 含 `xsec_token` 的完整笔记链接（仍会通过客户端重新分享）。
- 单独的 24 位十六进制笔记 ID。

上面的“笔记ID”是占位说明，使用时需要替换成真实 ID。当前输入解析依赖笔记 ID；只有 `xhslink.com` / `xhslink.cn` 短链而不包含 ID 的文字不能直接作为输入。客户端复制出来的这两类官方短链则支持自动展开。

### 停止与重试

点击 **停止** 后，工具会在当前链接处理结束后停止，并导出已处理结果，不是立即中断正在进行的点击或请求。

对加载、分享和复制等暂时性故障，页面恢复成功后最多自动重试一次。需要手动重试时，将失败项的原链接或 ID 再粘贴到输入框，点击开始即可。权限不足、窗口离开前台或无法安全恢复首页时会停止批次。

## 如何看结果

结果区每行对应一条去重后的输入；Excel 包含序号、原始链接、笔记 ID、状态、新链接、说明和处理时间。

| 状态 | 含义 | 是否自动复制 |
| --- | --- | --- |
| 成功 | 已取得带 `xsec_token` 且笔记 ID 与本条一致的链接 | 是 |
| 待核验 | 已取得官方分享短链，但未能展开并核验目标笔记；短链保留在结果区和 Excel 中 | 否 |
| 已删除 | 客户端显示“当前内容无法展示”等无法查看提示时的统一结果标签，具体提示保留在 Excel 说明中 | 否 |
| 失败 | 加载、分享、复制、窗口状态或链接归属校验等环节失败；查看说明列定位原因 | 否 |

成功链接统一整理为：

```text
https://www.xiaohongshu.com/explore/笔记ID?xsec_token=客户端返回的凭证&xsec_source=app_share
```

“成功”表示已取得并核对分享链接，不代表已经逐一在浏览器中打开验证。删除、私密、仅粉丝可见等情况仍受平台权限限制。

## 常见问题

**提示没有识别到笔记 ID**

确认输入的是笔记详情链接或完整的 24 位 ID，不是作者主页、搜索页或不含 ID 的官方短链。

**提示需要辅助功能权限**

按上方授权步骤操作，注意选择当前使用的 App。移动安装位置或更换版本后，可能需要移除旧条目再重新添加。

**提示小红书窗口不在前台**

工具已停止点击。切回小红书，确认没有其他窗口遮挡，再在工具中重试未完成的链接。处理期间不要切换到其他应用。

**找不到分享按钮、复制链接，或剪贴板没有变化**

确认客户端已登录、页面已加载、窗口可见。默认坐标适配可能因客户端改版而失效；可尝试关闭坐标回退，仅使用控件识别。自动恢复后仍失败的条目会保留原因。

**某条显示“已删除”后还会继续吗？**

会先退出页面，并等待客户端延迟跳转结束，确认首页稳定后再继续。这段保护等待用于防止失效链接影响后续条目。

**为什么回到首页后有时还要等？**

短链网络请求尚未完成时仍需等待核验；正常情况下，返回首页、短链展开与最小间隔会重叠，不再重复确认已经稳定的首页。失效恢复和单次故障重试仍保留必要等待。

**可以隐藏小红书或同时操作其他应用吗？**

不建议。工具使用客户端窗口、鼠标和系统剪贴板；窗口离开前台时会停止点击。

**Excel 没有自动打开怎么办？**

到桌面的“小红书链接转换结果”文件夹查找本批文件，用 Excel、WPS 或其他支持 `.xlsx` 的软件打开。如果界面提示“Excel 保存失败”，按具体错误处理。

## 快捷键

## 从源码构建

安装 Xcode Command Line Tools（`xcode-select --install`），在 Apple Silicon Mac 上进入仓库目录执行：

```sh
./build.command
./小红书链接修复.app/Contents/MacOS/XHSLinkRepair --self-test
```

生成的 App 位于仓库根目录。构建脚本指定 `arm64-apple-macosx13.0` 目标，并使用固定签名标识。

自检覆盖失效页恢复、延迟跳转、分享链接归属、短链重定向、返回首页与网络展开的并行处理及剩余间隔计算。测试使用虚构 ID 和测试凭证，不请求真实笔记。

已在开发机器完成相关客户端样本测试；未在其他 Mac 或所有小红书版本上验证。工具不读取浏览器 Cookie、不保存账号信息、不生成或伪造 `xsec_token`；剪贴板和导出的结果文件会包含客户端实际返回的分享凭证。
