小红书链接修复 Windows / MuMu 预览版 0.1.0

1. 打开 MuMu 模拟器，打开安卓版小红书并完成登录。
2. 双击“小红书链接修复.exe”。程序会自动查找运行中的 MuMu 和已安装小红书的设备。
   如果没有找到 adb.exe，请选择 MuMu 安装目录 nx_main 下的 adb.exe。
   多个设备时，请明确选择要使用的设备。
3. 粘贴小红书笔记链接、官方短链、分享文案或 24 位笔记 ID，可混合多行或导入 TXT。
4. 点击“开始修复”。转换过程中不要在模拟器中切换页面，不要复制其他内容；Windows 剪贴板用于接收 MuMu 的分享结果。
5. 每条处理完成后自动保存 Excel。默认目录是“文档\小红书链接修复结果”。可点击“导出 Excel”另存或复制选中的链接。

成功：已从客户端重新分享，展开后笔记 ID 匹配且包含 xsec_token，不代表已验证浏览器展示。
待核验：客户端分享成功，但网络展开或签名核验尚未完成，保留分享短链。
需处理：需要登录/验证、剪贴板未同步或笔记 ID 不符，程序停止批次，请先处理提示。
失败：打开、控件识别或输入短链展开失败。说明列保存原因，不把网络失败当作删除。
停止后保留未处理行及已完成结果。重试时只粘贴需要重试的原始链接。

依赖 Windows x64、.NET Framework 4.8 和已安装的 MuMu；不需要另装 Python 或 Excel。
只使用客户端实际生成的分享参数，不伪造 token，不绕过访问权限，不读取账号密码或浏览器 Cookie。
首次使用 MuMu 的 ADB 连接时如出现确认，请核对为本机模拟器。程序不修改 ADB/系统安全设置。
当前版本不含自动更新、自动恢复上次输入、Excel 输入导入；批次结束自动保存 Excel。
输入、分享链接和结果仅保存在本机；网络请求仅用于官方短链展开。
